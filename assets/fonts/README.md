# Invoice fonts

`IBMPlexSansArabic-Regular.ttf` and `IBMPlexSansArabic-SemiBold.ttf` are IBM Plex Sans Arabic,
downloaded from the official IBM Plex repository:

<https://github.com/IBM/plex/tree/master/packages/plex-sans-arabic/fonts/complete/ttf>

Licensed under the SIL Open Font License 1.1; the full text is in `OFL.txt`. The invoice route reads
these files at runtime and Next traces them into the server bundle (`next.config.ts`,
`outputFileTracingIncludes`).
